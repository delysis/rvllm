"human-authored," but Codex authored both passages and continuations.
That string is wrong. The submitted source bytes are immutable inputs to
four queued jobs, so they are preserved with their original hash rather
than silently rewritten. This correction supersedes the source's
authorship claim. Treat the cases as synthetic investigator-authored text
held out from the **evaluated Gemma 4 checkpoint and candidate-selection
trials**, not as a human-authored or independently sampled corpus. Their
scores cannot qualify general language quality.

This is a correctness/quality diagnostic for the original BF16 Gemma 4
12B-it checkpoint. It is **not** a performance run, numerical oracle,
perplexity acceptance threshold, or promotion gate by itself. The two
prompt/continuation pairs in `heldout-text-v1.json` were written by Codex after the
combined Metal candidate and its prior benchmark prompts were frozen, and
before either route was scored on these targets. The continuations are
not generated by MLX, rvLLM, or Hugging Face. They
must not be changed in response to results. These are only two synthetic
cases, not a representative held-out corpus.

The four immutable queue manifests form a serial chain: map control,
map combined, reservoir control, reservoir combined. Each pins the
source/generator/prompt, model config and safetensor, tokenizer, CLI source,
separate frozen executable and selected metallib. The teacher-forced
readback runs after ordinary prefill and records every target's NLL, rank
and greedy token ID. Readback synchronization makes **all timing invalid**.
No thermal-stability wait is permitted; report every condition observation.

Before seeing data, the analysis is fixed as follows: retain all 28 and 36
positions, report each route's sum and mean NLL for each case, the
candidate-minus-control difference, every position where rank or greedy ID
differs, and the first **sampled greedy-ID** difference if any. The CLI's
`generated_token_ids` field contains the forced target sequence in this
mode, so equality in that field is a transport check, not model agreement.
Require exact prompt
and target IDs, unchanged pins, terminal queue success, and actual combined
